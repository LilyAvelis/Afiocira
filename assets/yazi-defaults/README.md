# Pinned Yazi defaults

`yazi.toml` and `keymap.toml` are copied from the upstream Yazi **v26.5.6**
`yazi-config/preset/` directory. The Settings adapter uses them to resolve default
General values and keybindings when the user's TOML does not override them.
They are reference inputs, not files written over the user's configuration.

Upstream: [sxyazi/yazi, v26.5.6](https://github.com/sxyazi/yazi/tree/v26.5.6/yazi-config/preset).

notice is included in [LICENSE](LICENSE). Refresh both presets and their
attribution together when changing the adapter's pinned Yazi version.
