# Afiocira 2.0.0

Большой выпуск: фото и видео, готовый видеодвижок, настоящая файловая навигация Yazi и команды без постоянного перехода в Проводник.

- Видео и звук через libmpv, миниатюры через FFmpeg.
- Actions в стиле Raycast, векторные иконки и управление формами с клавиатуры.
- Множественное выделение, копирование/вставка, дубликаты, F2, перетаскивание для открытия и удаление в корзину.
- Поиск Everything по Ctrl+Shift+K.
- Подпапки как отдельные ленивые альбомы: горизонтальное листание, независимые позиции, переходы вверх/вниз.
- Tab из обзора выделяет папку альбома в Yazi; Enter входит в его локальную галерею, Space открывает кадр.
- Изменение размера/веса в новую копию и проверенная конвертация PNG/JPEG/WebP.
- Исправлены светлые края выделения Yazi, центрирование, узкое окно и сброс кэша после переименования.

## Скачать

**Setup** — установка для текущего пользователя. **Portable ZIP** — распаковать всю папку и запустить Afiocira.exe; при необходимости установить приложенный VC++ Runtime. Yazi, поисковый помощник и шрифт включены. Установщик скачивает проверенные libmpv и FFmpeg напрямую у поставщиков: нужен Интернет. В Portable для видео сначала запустите Enable-Video.cmd. Сам Everything устанавливается отдельно и нужен только для поиска.

Проверено на Windows11 x64. Сборка без цифровой подписи. В SHA256SUMS.txt — контрольные суммы.

## Проверки и границы

129 unit/native тестов,3 doctest, строгий Clippy и живые API-сценарии навигации/файловых операций. Упакованная сборка отдельно проверена с изолированной конфигурацией.

Пока без массового F2, переназначения клавиш, полноценного цветового менеджмента и декодирования HEIC/AVIF. Конвертация — статические8-битные PNG/JPEG/WebP; неподдерживаемые случаи отклоняются. Поиск требует запущенного Everything. Подробности и лицензии — в README и комплекте приложения.
