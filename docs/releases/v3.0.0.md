# Afiocira 3.0.0 — Metadata, session history and photo editing

Version `v3.0.0`. The Windows workflow publishes the installer, portable ZIP and
checksums after successful checks and package verification.

## Changes

- **Own notes and tags in SQLite:** Ctrl+G opens Metadata for tags, comment and description. Saving is explicit; browsing folders and reading metadata do not register images.
- **Read-only file metadata:** supported XMP, EXIF/IPTC, ICC/header information and PNG generation data appear separately from Afio notes. Complete ComfyUI workflow JSON can be copied. It is not executed or silently imported.
- **Temporary SSD session history:** Ctrl+H opens version cards in Space. Ctrl+Z and Ctrl+Shift+Z restore exact bytes, format and path. Ctrl+S retains the current point and past while explicitly discarding the redo continuation. A new history-producing edit requires that decision when redo exists. Rotation and reflection do not create versions.
- **Three photo tools:** Light and Color, Details and Vignette provide fifteen controls plus a tone curve. Live preview, original comparison, Apply, Cancel and Reset share checked writes and session history. Curve output may rise or fall.
- **JPEG metadata preservation:** checked edits retain supported XMP and photometric metadata. Validation used a copy while retaining the original test source.
- **Everyday actions and fixes:** Copy Path, a persistent copy-confirmation preference, Metadata Escape/focus fixes, shortcut dispatch and editor submission fixes. Ctrl+L was manually validated by the user.

## Packages

Downloads and publication status: [GitHub Release v3.0.0](https://github.com/LilyAvelis/Afiocira/releases/tag/v3.0.0).
Setup installs for the current user; extract the portable ZIP completely.
Yazi, ES helper and the font are included. Everything is installed separately and
is required only for search. The installer or **Enable-Video.cmd** downloads
checksummed video runtimes directly from upstream; video binaries are not bundled.

Windows 11 x64 with a working OpenGL driver is the target. The installer is
unsigned. Verify downloads against **SHA256SUMS.txt**. See
[installation and build notes](../install-and-build.md).

## Verification and boundaries

The last reported local run passed 296 Rust unit/native tests and 3 doctests,
formatting and strict Clippy, supplemented by isolated native synthetic scenarios.
This does not replace verification of the final package or an independent install
on another unprepared computer. Actual package/publication results belong in
[Actions](https://github.com/LilyAvelis/Afiocira/actions) and the
[verification record](../release-3.0.md).

History is temporary and session-only. Normal shutdown removes owned snapshots;
a crash can leave recovery files. Photo editing supports static 8-bit
PNG/JPEG/WebP with conservative sRGB processing. JPEG is re-encoded at quality 95;
fine detail in reduced live preview is approximate. ICC metadata inspection does
not imply full color-managed display or editing.

HEIC/RAW, persistent history, Fork, tag search and dataset export are not included.
Ctrl+G UX is reserved for 3.1; persistent history for 3.2. ComfyUI execution remains
future work without an assigned version.
